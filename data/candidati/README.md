# Record esclusi

`esclusi.csv`: centri trovati nelle fonti ma **non** inseriti in `data/cras.csv`, con il motivo (centro chiuso, solo rapaci/uccelli/tartarughe, servizio di sola informazione o trasporto, nessun numero ritrovato nella fonte).
Per promuovere un record: verificare con una telefonata, poi aggiungerlo a `cras.csv` (vedi CONTRIBUTING.md).
